# API examples
- Health: `GET http://localhost:3000/api/health`
- List: `GET http://localhost:3000/api/internships?page=1&limit=3`
- Filter: `GET http://localhost:3000/api/internships?domain=Web%20Development&work_mode=Remote`
- Search: `GET http://localhost:3000/api/internships?search=Python`
- Detail: `GET http://localhost:3000/api/internships/1`
- Create/update/delete: use Postman with JSON; see README for the create body.
